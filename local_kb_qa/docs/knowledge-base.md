## 20. 本地知识库问答系统（RAG）⭐ 重点

**关键词**：RAG、知识库、问答系统、本地知识库、向量库、检索增强

【面试】这是我做得最完整的一个项目，全程一个人，从数据到界面全包。
技术栈是 Python + LangChain + Ollama + Chroma，嵌入模型用 bge-m3，模型跑 Qwen2.5-7B 的 GGUF 量化版，界面用 Gradio。
具体做的事：第一，文档加载和中文感知切分，chunk_size 设 500、overlap 设 50；第二，向量化入库并持久化；第三，把检索链设计成历史感知的，TOP_K 取 4，这样多轮对话能接上上下文；第四，用 Prompt 约束压幻觉；第五，用 Gradio 搭多轮对话界面。
成果就是一套完全离线跑的知识库问答，数据不出本地，回答带来源引用。

【书面】本地知识库问答系统（RAG）｜独立开发（全栈）｜个人重点项目
技术栈：Python、LangChain、Ollama、Chroma 向量数据库、bge-m3 嵌入模型、Qwen2.5-7B（GGUF 量化）、Gradio

工作内容：文档加载与中文感知切分（chunk_size 500 / overlap 50）；向量化入库与持久化；历史感知检索链设计（TOP_K 4）；Prompt 约束降低幻觉；Gradio 多轮对话界面搭建

成果：完全离线运行，数据全程不出本地，支持基于文档内容问答并带来源引用。
